# 🏥 MediPilot Nexus

> **An AI-Powered Smart Healthcare Management Platform**

MediPilot Nexus is a modern healthcare management platform designed to simplify communication and workflows between **Patients**, **Hospitals**, and **Insurance Providers**. The platform offers dedicated dashboards for each stakeholder, enabling appointment scheduling, medical record management, AI-assisted healthcare insights, insurance claim tracking, and health monitoring through a responsive and user-friendly web application.

## ⚙️ Installation

### Clone the repository

```bash
git clone https://github.com/your-username/MediPilot-Nexus.git
```

### Navigate to the project

```bash
cd MediPilot-Nexus
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
